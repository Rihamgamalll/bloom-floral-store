BLOOM V10 — CALM GSAP

What changed from V9:
- Removed the page-wide fixed flying floral layer (main source of visual noise and extra work on scroll).
- Rebuilt the atelier as one clear GSAP story using only 4 stem elements + 1 final bouquet.
- Shorter pinned desktop sequence; mobile is NOT pinned.
- Motion uses transforms/opacity rather than repeated blur/filter animation.
- Reworked reveal system with ScrollTrigger.batch to reduce the number of independent triggers.
- Added controlled clip-path reveals for editorial imagery and subtle occasion-card choreography.
- Kept the warm ivory / muted rosewood / sage / espresso palette consistent.
- No new dependencies.
